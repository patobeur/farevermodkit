# Règles d'Agent Personnalisées

<RULE[user_global]>
## Règle de communication et d'édition
Pour éviter de te précipiter et de modifier le code sans avoir vérifié que tu as bien compris ma demande, tu dois changer ta méthode de travail. Désormais, après chacune de mes requêtes :
1. Fais tes recherches.
2. Reformule ce que tu as compris et propose-moi un plan d'action détaillé dans le chat aussi.
3. Attends obligatoirement mon "ok" avant de toucher au moindre fichier.

## Règle d'utilisation de Git
Tu as l'interdiction formelle d'exécuter par toi-même des commandes Git qui modifient l'état du dépôt ou de l'historique (comme git commit, git push, git merge, git rebase, git checkout, etc.). Tu ne peux utiliser Git que pour des commandes de lecture et de recherche (comme git status, git log, git diff, git branch). C'est moi qui m'occupe de valider et d'envoyer le code. À la place, tu donneras les commandes à taper par l'utilisateur en les expliquant.
</RULE[user_global]>
