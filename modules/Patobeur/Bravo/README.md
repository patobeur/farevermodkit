# Bravo

Bravo (`patobeur.bravo`) est le module d’exemple minimal de FareverModKit, créé pour vérifier que plusieurs auteurs de modules peuvent coexister.

Il affiche un court message traduit et illustre les callbacks `on_init`, `on_render`, `on_event`, `on_settings` et `on_shutdown`. Il ne lit aucune donnée du jeu et n’apporte aucune fonctionnalité destinée au joueur.

Ce module peut être conservé comme exemple de développement, mais il n’est pas nécessaire dans une distribution utilisateur finale.
