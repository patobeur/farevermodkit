Le manuel complet pour installer le modkit, compiler les sources et configurer l'environnement.

Installation (Pour les joueurs)

Vous souhaitez simplement utiliser le mod ? C'est très simple !

  1. Téléchargez la dernière Release depuis GitHub.
  2. Extrayez le contenu de l'archive.
  3. Copiez l'intégralité du contenu extrait directement dans le dossier d'installation de votre jeu Farever (là où se trouve Farever.exe).

Attention : Ne pas utiliser simultanément farever-minimap et ce mod. Les deux installent un overlay (via dxgi.dll) qui va entrer en conflit.

Pour les développeurs (Compilation & Fork)

Envie de bidouiller, d'améliorer le code ou de faire un Fork du projet ? Voici comment prendre le projet en main :

Prérequis

  • Node.js 18 ou plus récent.
  • Visual Studio avec les outils MSVC C++ x64 et un SDK Windows.

Compiler depuis les sources

Ouvrez un terminal à la racine du dépôt cloné. L'ordre des commandes est crucial car les offsets de mémoire et le hash du jeu sont compilés directement dans la DLL.

node tools/gen-offsets.mjs
host\build.cmd
install.cmd

En cas de mise à jour du jeu

Si Farever reçoit une mise à jour, les offsets vont changer. Utilisez le script de mise à jour pour recalculer les accès :

node tools/update.mjs --fix

DLL, code source et risques

Le code source de dxgi.dll se trouve dans host\src. host\build.cmd le compile avec MSVC et produit host\build\dxgi.dll. L'installateur ne compile pas : il vérifie le jeu puis copie une DLL déjà construite.

Cette DLL doit rester à la racine car Windows la charge comme proxy DXGI. Elle charge ensuite le vrai DXGI système par son chemin absolu.

Risque réel : une DLL native s'exécute dans le processus du jeu avec les droits de l'utilisateur. Un bug peut provoquer un crash et une DLL malveillante pourrait faire davantage. Le code actuel du mod ne contient aucune communication réseau, mais il lit la mémoire du jeu et intercepte la présentation DirectX.
  • Consulter docs\dll-safety.md pour le détail.
  • Compiler localement pour ne pas dépendre d'un binaire tiers.
  • Comparer le SHA-256 de la DLL compilée et installée.
  • Le mod refuse les lectures lorsque le hash du jeu ne correspond pas.

Désinstallation

uninstall.cmd --game "<dossier-Farever>"

Supprimer seulement dxgi.dll suffit à empêcher le chargement natif. Les données restent conservées. Pour supprimer les fichiers générés :

uninstall.cmd --purge --game "<dossier-Farever>"

Les routes créées manuellement sont protégées sauf si --force est ajouté.
