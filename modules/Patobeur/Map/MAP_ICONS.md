# Icônes attendues pour Map

À placer dans :

modules/Patobeur/Map/assets/

Noms exacts :

- zoom-in.png — bouton zoom avant
- zoom-out.png — bouton zoom arrière
- chests.png — afficher/masquer les coffres
- orbs.png — afficher/masquer les orbes
- players.png — afficher/masquer les joueurs
- waypoints.png — afficher/masquer les points de passage

Format recommandé :

- PNG avec transparence ;
- carré, 32×32 ou 64×64 pixels ;
- fond transparent ;
- une seule icône par fichier ;
- noms en minuscules, exactement comme ci-dessus.

Les icônes ne sont pas encore obligatoires : les boutons texte restent utilisés tant que les images ne sont pas présentes.
